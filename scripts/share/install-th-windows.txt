PoodPim (พูดพิมพ์) — พิมพ์ด้วยเสียงภาษาไทย สำหรับ Windows
==========================================================

กดปุ่ม Alt ขวาค้างไว้ พูด แล้วปล่อย ข้อความจะถูกพิมพ์ลงในโปรแกรมที่เคอร์เซอร์อยู่
ใช้ได้ทุกโปรแกรม เช่น LINE, Word, Chrome

ใช้ได้กับ: Windows 10 / 11 แบบ 64-bit
ต้องต่ออินเทอร์เน็ต (เสียงถูกส่งไปถอดที่เซิร์ฟเวอร์)


ติดตั้ง
-------
1. แตกไฟล์ zip ก่อน: คลิกขวาที่ไฟล์ zip › Extract All…
   (ห้ามเปิดจากในไฟล์ zip โดยตรง ไฟล์ทุกตัวในโฟลเดอร์ PoodPim ต้องอยู่ด้วยกัน)
   แล้วย้ายโฟลเดอร์ PoodPim ไปไว้ที่ที่ไม่ลบทิ้ง เช่น Documents

2. ดับเบิลคลิก PoodPim.exe
   ถ้าขึ้นหน้าจอสีน้ำเงิน "Windows protected your PC"
   ให้กด "More info" แล้วกด "Run anyway"

   ถ้าขึ้นว่า "MSVCP140.dll was not found" หรือ "VCRUNTIME140.dll was not found"
   ให้ติดตั้ง Microsoft Visual C++ Redistributable จาก
   https://aka.ms/vs/17/release/vc_redist.x64.exe
   แล้วเปิด PoodPim.exe ใหม่

3. โปรแกรมไม่มีหน้าต่าง ให้ดูไอคอนรูปไมโครโฟนที่มุมขวาล่างของจอ (ข้างนาฬิกา)
   ถ้าไม่เห็น ให้กดลูกศร ^ ข้างนาฬิกา ไอคอนอาจซ่อนอยู่ในนั้น
   (ลากไอคอนออกมาไว้ข้างนาฬิกาได้ จะได้เห็นสถานะตลอด)

4. ใส่ API URL และ API key ที่ได้รับมา
   กด Alt ขวาครั้งแรก จะมีช่องให้ใส่ API URL ก่อน แล้วตามด้วยช่อง API key
   วางแต่ละค่าแล้วกด OK
   (หรือคลิกไอคอนไมโครโฟน › Server URL & API key…)

5. ถ้าพูดแล้วไม่ได้ข้อความ ให้เปิดสิทธิ์ไมโครโฟน:
   Settings › Privacy & security › Microphone
   เปิด "Microphone access" และ "Let desktop apps access your microphone"


วิธีใช้
------
• กด Alt ขวาค้างไว้ → พูด → ปล่อย
• แตะ Alt ขวาแล้วปล่อยทันที = ฟังไปเรื่อยๆ ไม่ต้องกดค้าง แตะอีกครั้งเมื่อพูดจบ
• กด Esc = ยกเลิก
• ดูสถานะจากสีไอคอนไมโครโฟน: แดง = กำลังฟัง, ส้ม = กำลังถอดเสียง
• พูดยาวได้สูงสุด 10 นาทีต่อครั้ง
• ถ้าไม่ได้ใช้นานเกิน 3 นาที ครั้งถัดไปเซิร์ฟเวอร์ต้องตื่นก่อน อาจรอราว 15 วินาที
  ครั้งต่อๆ ไปจะเร็ว (ราว 1 วินาที)
• พิมพ์ซ้ำครั้งล่าสุด: คลิกไอคอนไมโครโฟน › Paste last transcript

PoodPim จะเปิดเองทุกครั้งที่เปิดเครื่อง
ถ้าไม่ต้องการ: คลิกไอคอนไมโครโฟน › เอาเครื่องหมายถูกหน้า Start at login ออก
ถ้าย้ายโฟลเดอร์ PoodPim ไปที่อื่น ให้เปิด PoodPim.exe จากที่ใหม่ 1 ครั้ง โปรแกรมจะจำตำแหน่งใหม่เอง


ความเป็นส่วนตัว
---------------
เสียงพูดจะถูกส่งไปถอดเป็นข้อความที่เซิร์ฟเวอร์ AWS ในกรุงเทพฯ
เซิร์ฟเวอร์ไม่ได้บันทึกไฟล์เสียงหรือข้อความเก็บไว้

กรุณาอย่าส่ง API URL และ API key ต่อให้คนอื่น


มีปัญหา
-------
• กด Alt ขวาแล้วไม่มีอะไรเกิดขึ้น: คลิกไอคอนไมโครโฟน ดูบรรทัดบนสุด
  ถ้าขึ้นว่า "API key was rejected" แปลว่า key ไม่ถูกต้อง กด Alt ขวาแล้วใส่ใหม่
• ข้อความไม่ถูกพิมพ์: ให้คลิกในช่องพิมพ์ก่อนกดปุ่ม
• โปรแกรมที่เปิดแบบ Run as administrator จะรับข้อความจาก PoodPim ไม่ได้
